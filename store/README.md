# Store & branding

Semua gambar untuk listing toko dan identitas aplikasi DOKU.

| Folder | Isi |
|---|---|
| `play_console/` | Siap unggah ke Google Play Console: ikon 512×512, grafik fitur 1024×500, dan 7 screenshot ponsel 1080×1920 (urut sesuai nomor) |
| `app_screenshots/` | Screenshot mentah aplikasi (1080×2340) yang dipakai di mockup |
| `branding/` | Logo final (`logo.svg`, `logo_1024.png`), ikon Play Store, preview ikon launcher |
| `branding/options/` | Opsi logo sudut pandang samping (A–D) |
| `branding/arsip/` | Logo minimalis pertama (dompet berkacamata) dan perbandingannya dengan logo lama |
| `branding/mascot/` | Opsi maskot dompet: dengan kaki (1–4), versi gradien, tanpa kaki (5–8), variasi kartu (6A–6D), dan kombinasi final |
